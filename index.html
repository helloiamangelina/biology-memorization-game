🧬 Genetic Code

mRNA codons are read 5′ → 3′ in groups of three nucleotides.

Important: the codon table is written for mRNA. A coding DNA triplet has the same letters except T replaces U. A template DNA strand is complementary and antiparallel. AUG codes methionine and usually serves as the start codon; UAA, UAG, UGA are stop codons.
